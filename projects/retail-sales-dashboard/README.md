# Retail Sales & Financial Performance Dashboard
**Power BI · Excel · DAX**

## Overview
An interactive dashboard for exploring retail revenue, transaction counts, average order value, sales volume, and product-category contributions.

## Tools
Power BI · Microsoft Excel · DAX

## Dashboard Features
- Revenue, transaction count, average order value, and quantity indicators
- Daily sales trends
- Year-to-date revenue analysis
- Product-category comparisons: Books, Electronics, Apparel, and Home & Kitchen

## Portfolio Highlights
| KPI | Reported value |
| --- | --- |
| Total revenue | Approximately SAR 311.01 thousand |
| Transactions | 500 |
| Average order value | SAR 622.01 |
| Units sold | Approximately 1 thousand |

The figures use the rounded values shown in the portfolio. Source data is needed to reproduce exact totals and calculations.

## Available Material
A dashboard preview is shown in the [portfolio](https://statistical-portfolio.my.canva.site/statistical-portfolio-zahrah-faleh-alodhaylah).

The supplied PDF does not include a dedicated interactive link for this dashboard. The original PBIX file, source workbook, and DAX definitions are not included in this folder.
