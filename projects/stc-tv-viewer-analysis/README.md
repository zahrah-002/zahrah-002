# STC TV User Behavior & Streaming Analytics
**stc × Misk · Virtual training project**

## Overview
An exploratory analysis of STC TV streaming logs to describe viewing patterns, compare content types, and examine use of SD and HD streaming quality.

## Tools
Python · Google Colab · Pandas · Data visualization

## Analysis
- Exploratory data analysis and descriptive viewer profiling
- Examination of right-skewed viewing distributions
- Comparisons between movie and series viewing
- Comparisons of SD and HD streaming usage

## Portfolio Highlights
| Measure | Reported result |
| --- | --- |
| Average watch time | Approximately 20.5 minutes |
| Series watch time per user | Approximately 65.39 hours |
| Movie users | Approximately 11.3 thousand |
| SD streaming share | 61.4% |

Metric definitions and aggregation should be read in the original report. Figures are reproduced from the portfolio and have not been independently recalculated.

## Interpretation
The portfolio frames movies as a potential acquisition focus and series as a potential retention focus. These are strategic interpretations of viewing patterns; the summary alone does not establish acquisition or retention effects.
